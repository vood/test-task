Problem

Design a system that manages GPU credits. Each credit grant has a unique id and is valid during a specific time window. Grants may overlap in time.

Because of network delays, events may arrive and be processed out of order with respect to their timestamp. At any point you may be asked for the total available credits at a given timestamp, or asked to consume credits at a given time.

Interface

CreditSystem() Initializes the credit system.
addGrant(grantId, amount, startTime, endTime) Registers a grant of amount credits valid on [startTime, endTime). Returns nothing.
getAvailableCredits(timestamp) Returns the total credits available at timestamp.
consumeCredits(timestamp, amount) Attempts to consume amount credits at timestamp. Returns a boolean.

Rules

  • A grant is active at t when startTime <= t < endTime.
  • Calls may arrive in any order relative to their timestamps. Every answer must reflect all events accepted so far, replayed in timestamp order. Two events with the same timestamp replay in arrival order.
  • getAvailableCredits(t) is the unconsumed total of the grants active at t, counting only consumptions whose timestamp is <= t.
  • A consumption draws from the active grants in order of soonest expiry first; ties break on the smaller grantId.
  • A consumption is accepted only if, after the replay, it and every previously accepted consumption are still fully satisfied. Otherwise it returns false, changes nothing, and is discarded — it is never retried.
  • Once accepted, a consumption is never revoked.
  • Consuming 0 always succeeds. Grant ids are unique, amounts are non-negative integers, timestamps are integers and may be negative.

Working here

  • Write plain JavaScript. Your file must define a top-level class CreditSystem.
  • ⌘/Ctrl + Enter runs the suite. Your code autosaves to this browser.
  • The scale case has a 5s budget; correctness is graded separately from speed.
  • An infinite loop freezes the tab — reload, your code is saved.
